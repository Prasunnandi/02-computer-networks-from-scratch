# Day 15 Lab: TCP Sliding Window & Flow Control Simulator

## For Beginners to Python

Welcome to Day 15! In this lab, we calculate the **Bandwidth-Delay Product (BDP)** and simulate the TCP sliding window.

### Key Concepts
- `BDP`: How many bytes are needed to keep a network pipe completely full.
- `Window Scale`: Modern high-speed internet links require Window Scale factors up to $2^{14}$ to saturate the pipe.

### How to Run
```bash
python sliding_window_sim.py
```
