# Day 19 Lab: Fast Retransmit (3 Duplicate ACKs) Simulator

## For Beginners to Python

Welcome to Day 19! In this lab, we simulate how TCP recovers from dropped packets in milliseconds without waiting for a timer to expire.

### Key Concepts
When 3 duplicate ACKs arrive for the same missing packet, TCP retransmits immediately!

### How to Run
```bash
python fast_retransmit_sim.py
```
